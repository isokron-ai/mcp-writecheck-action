# Regression ledger

One row per thing that went wrong, or could, in this repository: what it was, the tests that pin it, and the commit
that fixed it. Each test named here starts with its row's ID, except where a row names an older test by its full
name. IsoKron's cross-repo ledger (`docs/LEDGER.md` in isokron-ai/tool-qa) reads this table, so keep its four
columns and write tests as `file` › `test name`. A row can say how the problem was found with a "Found by: ..."
sentence.

- `R-WC-*`: the writecheck loop worker (`loop/`, `corpus.yml`, `loop-fixture.yml`; pull request 61; R-WC-14 to R-WC-18: the PostgreSQL fixture; R-WC-19 to R-WC-23: the Redis fixture; R-WC-24 to R-WC-27: fault sides on skips and the tidy after #66; R-WC-28 and R-WC-29: tool-qa version pins; R-WC-30 and R-WC-31: install faults from the second review of #70; R-WC-32 to R-WC-39: OCI images and crates, WC14, and the security review of #71; R-WC-40: stages that ran only on success, from the 27 Nov loop findings; R-WC-41: selftest's required PostgreSQL live tests).
- `R-INP-*`: the dispatch inputs of the T0 worker workflows (`selftest.yml`, `dogfood-*.yml`).
- `R-TSW-*`: the sealed result bundle of those T0 workers (`loop/t0-bundle.mjs`).
- `R-DSB-*`: the dogfood workers' sandbox (`dogfood/sbx.mjs`, `dogfood/sbx-cli/`, `loop/sandbox/dogfood-*.mjs`, `dogfood-sandbox-proof.yml`; 28 Nov 2026).
